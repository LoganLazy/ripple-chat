验证日期：2026-10-29。

- `npm run build`：TypeScript 检查与 Vite 生产构建通过。
- 安装后 npm audit：0 vulnerabilities（包含开发依赖）。
- Playwright：6 passed。
  1. 演示消息、回复、搜索、持久化与独立草稿。
  2. 创建演示房间、表情、空消息限制、未读过滤与主题切换。
